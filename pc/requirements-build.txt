# Build dependencies for the Windows receiver,
# pinned to the versions the last release was built with. Pinned rather than
# ranged because THIRD-PARTY-NOTICES documents what these exact versions put
# into the frozen exe; a different version can bundle a different set.
#
#     python -m pip install -r pc/requirements-build.txt
#     python pc/install_vgamepad.py
#
# vgamepad (0.1.0) is deliberately NOT listed. `pip install vgamepad` hangs on
# a machine that already has ViGEmBus, because its setup.py opens the MSI's
# Repair/Remove wizard and waits for a click. pc/install_vgamepad.py installs
# a patched copy instead; run it after this file.
#
# Python itself: 3.13.7 (x64) from python.org. The installer bundles that
# interpreter, so building with another one changes what ships.
